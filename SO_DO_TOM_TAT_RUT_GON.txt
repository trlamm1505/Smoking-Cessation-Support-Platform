│   ├─ Xem thông tin giới thiệu nền tảng
│   │   ├─ Mục tiêu, sứ mệnh, lợi ích
│   │   ├─ Giới thiệu chuyên gia/Coach
│   │   └─ Quy trình hỗ trợ thành viên
│   ├─ Đọc blog chia sẻ kinh nghiệm cai thuốc
│   │   ├─ Danh sách bài viết, lọc/tìm kiếm chủ đề

│       └─ Mô tả lợi ích & minh họa sử dụng

│   ├─ Tạo mật khẩu

LUỒNG 2 MEMBER (THÀNH VIÊN)
├─ 2.1 ĐĂNG NHẬP, THIẾT LẬP HỒ SƠ, ĐĂNG KÝ/NÂNG CẤP GÓI
│   ├─ Đăng nhập hệ thống
│   │   ├─ Nhập email/SĐT và mật khẩu
│   │   ├─ Xác thực thông tin, quên mật khẩu
│   │   └─ Báo lỗi/sai thông tin đăng nhập
│   ├─ Hoàn thiện hồ sơ cá nhân
│   │   ├─ Nhập họ tên, email, SĐT, địa chỉ, ảnh đại diện
│   │   ├─ Nhánh A (chưa trả phí): Chỉ xem hoặc chỉnh sửa thông tin cơ bản
│   │   └─ Nhánh B (đã trả phí): Tạo mới, chỉnh sửa đầy đủ (họ tên, nghề nghiệp, mô tả cá nhân, mạng xã hội...)
│   ├─ Khai báo lịch sử hút thuốc
│   │   ├─ Nhánh A: Nhập tổng số điếu/ngày cơ bản
│   │   └─ Nhánh B: Khai báo chi tiết (số năm hút, loại thuốc, tần suất, địa điểm, thời điểm, lý do hút)
│   ├─ Thiết lập mục tiêu cai thuốc
│   │   ├─ Nhánh A: Không được thiết lập/chỉnh sửa mục tiêu
│   │   └─ Nhánh B: Được thiết lập, chỉnh sửa mục tiêu cá nhân hóa, thêm cột mốc phụ
│   ├─ Chọn lý do cai thuốc
│   │   ├─ Chọn lý do mẫu (sức khỏe, tiết kiệm, gia đình...)
│   │   └─ Nhập lý do cá nhân
│   ├─ Chọn mua hoặc nâng cấp gói thành viên
│   │   ├─ Xem danh sách gói, quyền lợi, mức phí
│   │   ├─ Lựa chọn gói, hệ thống tạo đơn hàng
│   │   ├─ Chọn phương thức thanh toán (Momo, VNPay, thẻ ngân hàng...)
│   │   ├─ Thực hiện thanh toán và xác nhận giao dịch
│   │   ├─ Nếu thành công: cập nhật quyền, gửi hóa đơn, lưu lịch sử giao dịch
│   │   ├─ Xem/tải hóa đơn bất cứ lúc nào
│   │   ├─ Yêu cầu hoàn tiền khi cần (theo chính sách)
│   │   └─ Nhận thông báo duyệt/từ chối hoàn tiền
├─ 2.2 GHI NHẬN THÔNG TIN HÚT THUỐC HÀNG NGÀY
│   ├─ Truy cập "Theo dõi hút thuốc"
│   ├─ Ghi nhận số lượng thuốc hút
│   │   ├─ Nhánh A: Chỉ nhập tổng số điếu/ngày
│   │   └─ Nhánh B: Ghi nhận chi tiết từng lần hút (giờ, loại thuốc, tình huống)
│   ├─ Nhập tần suất hút (thời gian, địa điểm)
│   │   ├─ Nhánh A: Không hoặc rất hạn chế
│   │   └─ Nhánh B: Nhập chi tiết theo từng lần
│   ├─ Ghi nhận chi phí thuốc lá
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Nhập chi phí hàng ngày, hệ thống tổng hợp
│   └─ Hệ thống phân tích, khuyến nghị
│       ├─ Nhánh A: Khuyến nghị chung chung
│       └─ Nhánh B: Phân tích cá nhân hóa, cảnh báo nguy cơ, gợi ý liên hệ Coach
├─ 2.3 THEO DÕI TIẾN TRÌNH CAI THUỐC
│   ├─ Xem dashboard cá nhân
│   │   ├─ Nhánh A: Giao diện đơn giản, không có biểu đồ chi tiết
│   │   └─ Nhánh B: Biểu đồ chuyên sâu, so sánh tiến độ
│   ├─ Theo dõi số ngày không hút thuốc
│   ├─ Xem biểu đồ tiến độ cai thuốc
│   │   ├─ Nhánh A: Không hoặc rất hạn chế
│   │   └─ Nhánh B: Biểu đồ động, so sánh thành viên khác
│   ├─ Kiểm tra cải thiện sức khỏe theo thời gian
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Có báo cáo, so sánh cải thiện sức khỏe
│   └─ So sánh với mục tiêu đã đặt
│       ├─ Nhánh A: Không có
│       └─ Nhánh B: Có so sánh tiến độ, nhắc nhở điều chỉnh mục tiêu
├─ 2.4 NHẬN THÔNG BÁO VÀ ĐỘNG VIÊN
│   ├─ Nhận thông báo định kỳ
│   │   ├─ Nhánh A: Thông báo cơ bản, không định kỳ
│   │   └─ Nhánh B: Định kỳ, cá nhân hóa milestone/nguy cơ
│   ├─ Xem lý do cai thuốc
│   ├─ Nhận thông báo thành tích
│   │   ├─ Nhánh A: Không hoặc hạn chế
│   │   └─ Nhánh B: Đầy đủ, động viên mỗi mốc quan trọng
│   └─ Chia sẻ thành tích lên mạng xã hội
│       ├─ Nhánh A: Không có
│       └─ Nhánh B: Có thể chia sẻ Facebook/Zalo/Instagram
├─ 2.5 TƯƠNG TÁC VỚI CỘNG ĐỒNG
│   ├─ Tham gia diễn đàn thảo luận
│   │   ├─ Nhánh A: Đọc blog, hạn chế bình luận
│   │   └─ Nhánh B: Tạo chủ đề, bình luận, tương tác tự do
│   ├─ Chia sẻ kinh nghiệm cai thuốc
│   │   ├─ Nhánh A: Không hoặc chỉ xem
│   │   └─ Nhánh B: Đăng bài chia sẻ, up ảnh, clip
│   ├─ Đọc/bình luận blog của thành viên khác
│   │   ├─ Nhánh A: Bình luận hạn chế, cần duyệt trước
│   │   └─ Nhánh B: Bình luận tự do, trả lời, tag thành viên
│   ├─ Xem bảng xếp hạng, so sánh tiến độ
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Xem bảng xếp hạng, so sánh bạn bè
│   └─ Kết bạn, hỗ trợ lẫn nhau
│       ├─ Nhánh A: Không có
│       └─ Nhánh B: Kết bạn, nhắn tin, lập nhóm hỗ trợ
├─ 2.6 TƯ VẤN VỚI COACH
│   ├─ Đặt lịch tư vấn với Coach
│   │   ├─ Nhánh A: Không có quyền
│   │   └─ Nhánh B: Được chọn Coach, đặt lịch theo thời gian rảnh
│   ├─ Tham gia buổi tư vấn (video call/chat)
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Tham gia video call, chat, gửi câu hỏi trước
│   ├─ Nhận lời khuyên chuyên môn
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Lời khuyên chi tiết, tài liệu cá nhân hóa
│   ├─ Được tạo kế hoạch cai thuốc cá nhân hóa
│   │   ├─ Nhánh A: Không có
│   │   └─ Nhánh B: Nhận/tùy chỉnh kế hoạch do Coach lên
│   └─ Theo dõi, báo cáo tiến độ với Coach
│       ├─ Nhánh A: Không có
│       └─ Nhánh B: Cập nhật kết quả, nhận nhận xét, đặt lịch mới
└─ 2.7 ĐÁNH GIÁ VÀ PHẢN HỒI
    ├─ Rating các tính năng
    │   ├─ Nhánh A: Feedback, báo lỗi cơ bản
    │   └─ Nhánh B: Feedback chi tiết, rating Coach, ưu tiên xử lý
    ├─ Đánh giá Coach
    │   ├─ Nhánh A: Không có
    │   └─ Nhánh B: Đánh giá từng buổi/từng Coach
    ├─ Gửi feedback cải thiện hệ thống
    │   ├─ Cả hai nhánh: Gửi được, Nhánh B ưu tiên xét duyệt
    └─ Báo lỗi kỹ thuật
        ├─ Cả hai nhánh: Được báo lỗi
        └─ Nhánh B: Ưu tiên hỗ trợ nhanh hơn





LUỒNG 3: COACH (HUẤN LUYỆN VIÊN)
├─ 3.1 ĐĂNG NHẬP VÀ QUẢN LÝ HỒ SƠ
│   ├─ Đăng nhập với tài khoản Coach
│   │   ├─ Nhập username/password, xác thực, báo lỗi sai/quên mật khẩu
│   ├─ Cập nhật thông tin chuyên môn
│   │   ├─ Nhập/thay đổi họ tên, email, sđt, bằng cấp, lĩnh vực mạnh
│   │   └─ Thêm ảnh đại diện, mô tả bản thân
│   ├─ Thiết lập lịch làm việc
│   │   ├─ Chọn ngày làm/ngày nghỉ, khung giờ rảnh
│   │   ├─ Xem/chỉnh sửa/xóa lịch đã thiết lập
│   │   └─ Đồng bộ Google Calendar
│   └─ Xem danh sách thành viên được phân công
│       ├─ Xem toàn bộ thành viên đang phụ trách
│       ├─ Xem thông tin cơ bản, lọc/tìm kiếm
│       └─ Truy cập nhanh hồ sơ chi tiết thành viên
│
├─ 3.2 TƯ VẤN TRỰC TUYẾN
│   ├─ Xem lịch hẹn tư vấn
│   │   ├─ Danh sách lịch hẹn (lọc theo ngày/tuần/tháng)
│   │   └─ Trạng thái hẹn, thông báo nhắc tư vấn
│   ├─ Chuẩn bị thông tin thành viên trước buổi tư vấn
│   │   ├─ Xem hồ sơ thành viên, lịch sử, tài liệu, ghi chú
│   │  
│   ├
│   │
│   ├─ Ghi nhận nội dung tư vấn
│   │   ├─ Viết ghi chú/báo cáo kết quả
│   │   ├─ Lưu đánh giá tình trạng/thái độ
│   │   └─ Đính kèm tài liệu, hình ảnh, bài tập
│   └─ Đưa ra kế hoạch hành động cho thành viên
│       ├─ Đặt mục tiêu cụ thể, giao nhiệm vụ
│       ├─ Đặt lịch tư vấn tiếp theo
│       └─ Gửi tin nhắn/email tóm tắt kế hoạch
│
├─ 3.3 THEO DÕI VÀ HỖ TRỢ THÀNH VIÊN
│   ├─ Theo dõi tiến độ cai thuốc
│   │   ├─ Nhật ký cai thuốc từng ngày, biểu đồ tiến trình
│   │   └─ Đánh giá tiến bộ, cập nhật tình trạng sức khỏe
│   ├─ Gửi tin nhắn động viên định kỳ
│   │   ├─ Thiết lập gửi tự động cá nhân hóa
│   │   └─ Theo dõi phản hồi để tư vấn kịp thời
│   ├─ Phân tích dữ liệu hút thuốc
│   │   ├─ Thu thập dữ liệu chi tiết, trực quan hóa
│   │   └─ Phát hiện xu hướng tái nghiện/yếu tố ảnh hưởng
│   ├─ Điều chỉnh kế hoạch tư vấn khi cần
│   │   ├─ Xác định thành viên cần điều chỉnh
│   │   ├─ Đổi mục tiêu/phương pháp tư vấn
│   │   └─ Thông báo rõ ràng cho thành viên
│   └─ Báo cáo tình hình cho Admin
│       ├─ Tạo báo cáo tiến độ định kỳ
│       ├─ Đề xuất hỗ trợ hoặc can thiệp
│       └─ Tổng hợp báo cáo tuần/tháng
│
├─ 3.4 TẠO NỘI DUNG HỖ TRỢ

│   │   ├─ Xây dựng chủ đề, viết bài, đính kèm ảnh, xuất bản
│   ├─ Tạo video hướng dẫn cai thuốc
│   │   ├─ Viết kịch bản, quay/biên tập, tải video, quản lý kho video
│   ├─ Phát triển chương trình tư vấn mới
│   │   ├─ Nghiên cứu nhu cầu, thiết kế/thử nghiệm chương trình
│   │   └─ Triển khai chương trình mới đã duyệt
│   └─

LUỒNG 4 ADMIN (QUẢN TRỊ VIÊN)
├─ 4.1 QUẢN LÝ HỆ THỐNG
│   ├─ Đăng nhập admin panel
│   │   ├─ Nhập username/password, 2FA bảo mật, báo lỗi/quên mật khẩu
│   ├─ Kiểm tra tình trạng hoạt động hệ thống
│   │   ├─ Dashboard trạng thái (uptime, downtime, server, tài nguyên)
│   │   ├─ Cảnh báo lỗi bất thường
│   │   └─ Lịch sử vấn đề hệ thống
│   ├─ Cập nhật phần mềm & bảo mật
│   │   ├─ Danh sách cập nhật, bản vá, kiểm tra bảo mật
│   │   └─ Thông báo kết quả cập nhật
│   └─ Backup dữ liệu định kỳ
│       ├─ Thiết lập backup tự động (ngày/tuần/tháng)
│       ├─ Backup dữ liệu user, hệ thống, thanh toán
│       ├─ Phục hồi từ backup khi cần
│       └─ Kiểm tra tình trạng backup/cảnh báo lỗi
│
├─ 4.2 QUẢN LÝ NGƯỜI DÙNG
│   ├─ Xem danh sách người dùng (Coach, Member, Guest)
│   │   ├─ Tìm kiếm, lọc theo tên/email/trạng thái
│   ├─ Phê duyệt/từ chối đăng ký thành viên mới
│   │   ├─ Xem thông tin chi tiết, phê duyệt/từ chối, lý do
│   ├─ Quản lý quyền hạn từng loại user
│   │   ├─ Thiết lập, chỉnh sửa phân quyền theo vai trò
│   ├─ Xử lý khiếu nại & báo cáo vi phạm
│   │   ├─ Xem danh sách, phân loại, xử lý, phản hồi
│   ├─ Khóa/mở khóa tài khoản
│   │   ├─ Tạm khóa, khóa vĩnh viễn, mở khóa khi xử lý xong
│   └─ Quản lý đơn hàng/giao dịch tài chính
│       ├─ Xem lịch sử giao dịch, trạng thái thanh toán
│       ├─ Xử lý hoàn tiền khi cần
│       └─ Theo dõi thanh toán thành công/thất bại
│
├─ 4.3 QUẢN LÝ COACH
│   ├─ Tuyển dụng & đào tạo Coach mới
│   │   ├─ Đăng tuyển, quản lý hồ sơ ứng viên, phỏng vấn, cấp tài khoản, đào tạo
│   ├─ Phân công thành viên cho Coach
│   │   ├─ Danh sách Coach, số thành viên, phân công/chuyển đổi
│   ├─ Đánh giá hiệu suất Coach
│   │   ├─ Thu thập feedback, xuất báo cáo hiệu suất định kỳ
│   └─ Xử lý khiếu nại chất lượng tư vấn
│       ├─ Nhận khiếu nại, phản hồi, giải pháp khắc phục
│
├─ 4.4 QUẢN LÝ NỘI DUNG
│   ├─ Duyệt bài blog trước đăng
│   │   ├─ Xem trước nội dung, phê duyệt/từ chối, feedback lý do
│   ├─ Kiểm duyệt nội dung thành viên
│   │   ├─ Quản lý bình luận/chia sẻ, xử lý vi phạm
│   ├─ Cập nhật thông tin y tế & khoa học mới
│   │   ├─ Tổng hợp, đăng tải tài liệu, bài viết, video mới
│   └─ Quản lý thư viện tài liệu hỗ trợ
│       ├─ Tải lên, phân loại, chỉnh sửa, xóa/cập nhật tài liệu
│
├─ 4.5 DASHBOARD & BÁO CÁO TỔNG HỢP
│   ├─ Xem dashboard tổng quan hệ thống/người dùng/doanh thu
│   ├─ Thống kê số lượng người dùng theo thời gian (biểu đồ, báo cáo)
│   ├─ Phân tích tỷ lệ thành công cai thuốc
│   │   ├─ Báo cáo hiệu quả, phân tích tổng thể
│   ├─ Báo cáo doanh thu & chi phí vận hành
│   │   ├─ Xem báo cáo doanh thu, xuất/tổng hợp hóa đơn, đối soát ngân hàng/cổng thanh toán
│   └─ Đánh giá hiệu quả các tính năng
│       ├─ Báo cáo sử dụng tính năng, đề xuất cải thiện
│
└─ 4.6 PHÁT TRIỂN & CẢI TIẾN
    ├─ Thu thập feedback người dùng (khảo sát, form, email)
    ├─ Phân tích dữ liệu sử dụng tính năng, xác định thói quen/nhu cầu
    ├─ Lên kế hoạch phát triển tính năng mới (ưu tiên, roadmap)
    ├─ Phối hợp team phát triển (trao đổi, giao nhiệm vụ, quản lý tiến độ)
    └─ Test & triển khai cập nhật (test nội bộ, xác nhận ổn định, triển khai chính thức)


LUỒNG 5 TÍCH HỢP HỆ THỐNG (5)
├─ 5.1 HỆ THỐNG THÔNG BÁO TỰ ĐỘNG
│   ├─ Trigger (Kích hoạt)
│   │   ├─ Milestone: 1 ngày/tuần/tháng/3-6-12 tháng không hút
│   ├─ Process (Xử lý)
│   │   ├─ Xác nhận milestone từ nhật ký cai thuốc
│   │   ├─ Tạo thông báo cá nhân hóa (lời chúc, lợi ích sức khỏe, gợi ý mục tiêu mới)
│   │   └─ Xử lý thông báo tức thì hoặc theo lịch
│   └─ Output (Hình thức gửi)
│       ├─ Notification push (app/web)
│       ├─ Email chúc mừng
│       ├─ SMS nhắc nhở/chúc mừng
│       └─ Tích hợp đa kênh (Zalo, Messenger…)
│
├─ 5.2 HỆ THỐNG PHÂN TÍCH DỮ LIỆU
│   ├─ Input (Dữ liệu vào)
│   │   ├─ Nhật ký hút thuốc: số điếu/ngày, tần suất, thời điểm, tâm trạng/yếu tố ảnh hưởng
│   ├─ Process (Phân tích)
│   │   ├─ Tổng hợp dữ liệu hàng ngày/tuần
│   │   ├─ Phân tích xu hướng: giảm/tăng số thuốc, xác định thời điểm dễ tái nghiện
│   │   ├─ Phân tích yếu tố ảnh hưởng (stress, môi trường…)
│   │   └─ Dự đoán nguy cơ tái phát bằng AI/ML
│   └─ Output (Kết quả)
│       ├─ Khuyến nghị cá nhân hóa (hành động, nhắc Coach điều chỉnh)
│       ├─ Cảnh báo sớm tới Coach/Admin
│       └─ Cảnh báo nhẹ nhàng tới thành viên
│
├─ 5.3 HỆ THỐNG XẾP HẠNG VÀ THÀNH TÍCH
│   ├─ Input (Dữ liệu vào)
│   │   ├─ Tiến độ cai thuốc, ngày liên tục không hút, milestone, tham gia thử thách
│   ├─ Process (Xử lý xếp hạng)
│   │   ├─ Tính điểm: số ngày liên tục, thử thách, tương tác
│   │   ├─ Cập nhật thứ hạng liên tục (ngày/tuần/tháng)
│   │   └─ Điều chỉnh/cân đối điểm số tự động
│   └─ Output (Hiển thị kết quả)
│       ├─ Bảng xếp hạng công khai (lọc theo thời gian, tìm kiếm)
│       └─ Huy hiệu thành tích cá nhân (gán tự động, hiển thị hồ sơ)
│
├─ 5.4 HỆ THỐNG BÁO CÁO ĐỊNH KỲ
│   ├─ Schedule (Lịch trình)
│   │   ├─ Hàng ngày: báo cáo nhanh tình trạng
│   │   ├─ Hàng tuần: báo cáo chi tiết tiến độ/hiệu quả tư vấn
│   │   └─ Hàng tháng: báo cáo tổng hợp, xu hướng dài hạn
│   ├─ Process (Tạo báo cáo)
│   │   ├─ Tự động tổng hợp dữ liệu (sử dụng, người dùng mới/hoạt động, hiệu quả, doanh thu, chi phí…)
│   │   ├─ Xuất báo cáo theo mẫu, trình bày rõ ràng
│   │   └─ Kiểm tra chất lượng, xác thực dữ liệu trước khi gửi
│   └─ Recipients (Người nhận)
│       ├─ Admin (tổng quan, doanh thu, hiệu quả)
│       ├─ Coach (báo cáo tiến độ, cảnh báo, hiệu quả cá nhân)
│       └─ Stakeholder (ban lãnh đạo, nhà đầu tư, bộ phận tài chính, marketing…)
│
└─ 🚩 Các tính năng bổ sung NẾU CẦN
    ├─ Dashboard tổng hợp (tích hợp kết quả các hệ thống)
    ├─ Lưu trữ báo cáo & lịch sử thông báo
    ├─ Feedback trực tiếp trên thông báo/báo cáo
    └─ Tích hợp công cụ phân tích nâng cao (Google Analytics, Power BI…)
