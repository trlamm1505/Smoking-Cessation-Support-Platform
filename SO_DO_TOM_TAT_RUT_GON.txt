LUỒNG 5 TÍCH HỢP HỆ THỐNG (5)
├─ 5.1 HỆ THỐNG THÔNG BÁO TỰ ĐỘNG
│   ├─ Trigger (Kích hoạt)
│   │   ├─ Milestone: 1 ngày/tuần/tháng/3-6-12 tháng không hút
│   ├─ Process (Xử lý)
│   │   ├─ Xác nhận milestone từ nhật ký cai thuốc
│   │   ├─ Tạo thông báo cá nhân hóa (lời chúc, lợi ích sức khỏe, gợi ý mục tiêu mới)
│   │   └─ Xử lý thông báo tức thì hoặc theo lịch
│   └─ Output (Hình thức gửi)
│       ├─ Notification push (app/web)
│       ├─ Email chúc mừng
│       ├─ SMS nhắc nhở/chúc mừng
│       
│
├─ 5.2 HỆ THỐNG PHÂN TÍCH DỮ LIỆU
│   ├─ Input (Dữ liệu vào)
│   │   ├─ Nhật ký hút thuốc: số điếu/ngày, tần suất, thời điểm, tâm trạng/yếu tố ảnh hưởng
│   ├─ Process (Phân tích)
│   │   ├─ Tổng hợp dữ liệu hàng ngày/tuần
│   │   ├─ Phân tích xu hướng: giảm/tăng số thuốc, xác định thời điểm dễ tái nghiện
│   │   ├─ Phân tích yếu tố ảnh hưởng (stress, môi trường…)
│   │   
│   └─ Output (Kết quả)
│       ├─ Khuyến nghị cá nhân hóa (hành động, nhắc Coach điều chỉnh)
│       ├─ Cảnh báo sớm tới Coach/Admin
│       └─ Cảnh báo nhẹ nhàng tới thành viên
│
├─ 5.3 HỆ THỐNG XẾP HẠNG VÀ THÀNH TÍCH
│   ├─ Input (Dữ liệu vào)
│   │   ├─ Tiến độ cai thuốc, ngày liên tục không hút, milestone, tham gia thử thách
│   ├─ Process (Xử lý xếp hạng)
│   │   ├─ Tính điểm: số ngày liên tục, thử thách, tương tác
│   │   ├─ Cập nhật thứ hạng liên tục (ngày/tuần/tháng)
│   │   └─ Điều chỉnh/cân đối điểm số tự động
│   └─ Output (Hiển thị kết quả)
│       ├─ Bảng xếp hạng công khai (lọc theo thời gian, tìm kiếm)
│       └─ Huy hiệu thành tích cá nhân (gán tự động, hiển thị hồ sơ)
│
├─ 5.4 HỆ THỐNG BÁO CÁO ĐỊNH KỲ
│   ├─ Schedule (Lịch trình)
│   │   ├─ Hàng ngày: báo cáo nhanh tình trạng
│   │   ├─ Hàng tuần: báo cáo chi tiết tiến độ/hiệu quả tư vấn
│   │   └─ Hàng tháng: báo cáo tổng hợp, xu hướng dài hạn
│   ├─ Process (Tạo báo cáo)
│   │   ├─ Tự động tổng hợp dữ liệu (sử dụng, người dùng mới/hoạt động, hiệu quả, doanh thu, chi phí…)
│   │   ├─ Xuất báo cáo theo mẫu, trình bày rõ ràng
│   │   └─ Kiểm tra chất lượng, xác thực dữ liệu trước khi gửi
│   └─ Recipients (Người nhận)
│       ├─ Admin (tổng quan, doanh thu, hiệu quả)
│       ├─ Coach (báo cáo tiến độ, cảnh báo, hiệu quả cá nhân)
│       └─ Stakeholder (ban lãnh đạo, nhà đầu tư, bộ phận tài chính, marketing…)
│
└─ 🚩 Các tính năng bổ sung NẾU CẦN
    ├─ Dashboard tổng hợp (tích hợp kết quả các hệ thống)
    ├─ Lưu trữ báo cáo & lịch sử thông báo
    ├─ Feedback trực tiếp trên thông báo/báo cáo
    └─ Tích hợp công cụ phân tích nâng cao (Google Analytics, Power BI…)
